# Banlist Commands

Banlist commands inspect the official blocklist maintained by each Minecraft Bedrock Realm. This is separate from Realm Bot's **Global Ban** review system.

These commands require a connected server and their named Realm Bot command permission. Discord Administrators bypass the custom role map.

## Commands

- [`/banlist all`](all.md) - list the selected Realm's official blocklist.
- [`/banlist lookup`](lookup.md) - check whether a player is blocked.
- [`/db report`](report.md) - submit evidence for internal Global Ban review.

Use [`/realm ban`](../Realm/ban.md) and [`/realm unban`](../Realm/unban.md) to change official Realm blocklists. For shared failures, see [Command Troubleshooting](../troubleshooting.md).
