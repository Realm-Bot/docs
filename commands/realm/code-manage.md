# `/realm code-manage`

Manage active invite codes for the Realm interactively.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm code-manage <realm>`

**Interactive Features**:
- **Add Code**: Create a new invite link.
- **Disable/Enable**: specific codes.
- **Make Permanent**: Remove expiration.
- **Set Expiration**: Set when a code expires (30m - 7d).
- **Delete**: Remove a code.
