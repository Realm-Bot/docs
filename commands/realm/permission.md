# `/realm permission`

Changes a player's permission level on the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm permission <user> <permission> [realm]`

**Arguments**:
- `user` (Required): The player to modify.
- `permission` (Required): The permission level: `Visitor`, `Member`, or `Operator`.
- `realm` (Optional): The realm to apply changes to. Defaults to all.
