# `/disconnect`

Disconnect your Xbox account from the discord server.

- **Permissions**: Authorized Users Only
- **Usage**: `/disconnect [guild]`

**Arguments**:
- `guild` (Optional): If `True`, it will delete all data associated with this guild from the database. Default is `False` (just unlinks account).
