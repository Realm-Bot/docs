# `/premium`

Provides a link to Realm Bot subscription information in the dashboard.

## Syntax

`/premium`

No Realm Bot custom command permission, connected account, or existing Premium subscription is required. The command must still be used in a Discord server.

## Claim a Premium Gift

A Premium gift link is separate from the `/premium` command. Share it privately: an unused link is not reserved for a named recipient.

1. Open the gift link. If Discord shows a **Claim Gift** button, it opens the dashboard; it does not redeem the gift.
2. Sign in with Discord if prompted. Check the account that will receive the time, the gift duration and the expiry.
3. Select **Claim Gift** on the dashboard. A successful claim uses the code once and adds **30 days per gifted month**, starting now or at the end of existing Premium time, whichever is later.

An unknown, expired or already-redeemed code cannot be claimed. The creator can regenerate an unredeemed link: the old code is replaced and the replacement is valid for **two days**. For an original link, use the expiry shown on its gift page.

For Premium time earned by referring another Realm owner, see [Referrals](../../Tools/referrals.md).
