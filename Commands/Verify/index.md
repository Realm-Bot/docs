# Verify Commands

Verify commands support Microsoft/Xbox account linking for Discord members. The panel can trigger configured role, nickname, review, and Realm invitation workflows.

Publishing the panel requires a connected server, the `command.verify.embed` Realm Bot permission, and suitable Discord channel permissions.

## Commands

- [`/verify embed`](embed.md) - post the public account-linking panel in the current channel.

Place verification review messages in a staff-only channel and restrict access through Discord channel permissions. See [Account Linking](<../../Server Dashboard/server-account-linking.md>) for configuration and [Command Troubleshooting](../troubleshooting.md) for shared failures.
