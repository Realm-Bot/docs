# `/rank`

Displays a rank card for a user, showing their level and XP earned through playing on the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/rank <realm> [user]`

**Arguments**:
- `realm` (Required): The realm to check rank on.
- `user` (Optional): The user to check. Defaults to yourself.
