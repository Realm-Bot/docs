# `/leaderboard`

Provides a link to the server's web leaderboard.

- **Permissions**: Authorized Users Only
- **Usage**: `/leaderboard`

**Response**:
- A button linking to `https://dashboard.realmbot.dev/leaderboard/<server_id>`.
