# Invite Commands

Invite commands manage `realmbot.link` web entry points. They are separate from official Realm codes managed through [`/realm code-manage`](../Realm/code-manage.md).

These commands require a connected server and their named Realm Bot command permission. They do not require Premium.

## Commands

- [`/invites create`](create.md) - create a reusable managed link.
- [`/invites temp`](temp.md) - create a one-use link that expires after 24 hours.
- [`/invites list`](list.md) - inspect managed link records.
- [`/invites delete`](delete.md) - permanently remove a managed link record.

Treat every active link as an entry point to the Realm. Limit its audience, uses, and lifetime appropriately. See [Invite Links](<../../Server Dashboard/server-invites.md>) for dashboard management and [Command Troubleshooting](../troubleshooting.md) for shared failures.
