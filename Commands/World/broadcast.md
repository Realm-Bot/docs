# `/world broadcast`

Broadcasts a message to the in-game chat.

- **Permissions**: Authorized Users Only (Premium)
- **Usage**: `/world broadcast <message> [realm]`

**Arguments**:
- `message` (Required): The message to send to the server.
- `realm` (Optional): The realm to broadcast to. Defaults to all.
