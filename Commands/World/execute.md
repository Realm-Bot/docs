# `/world execute`

Executes a console command on the Realm.

- **Permissions**: Authorized Users Only (Premium)
- **Usage**: `/world execute <command> [realm]`

**Arguments**:
- `command` (Required): The command to run (e.g., `/time set day`).
- `realm` (Optional): The realm to execute on. Defaults to all.
