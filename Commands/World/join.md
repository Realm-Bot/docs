# `/world join`

Connects the bot to the Realm's game server. This allows the bot to track chats, events, and interactions in real-time.

- **Permissions**: Authorized Users Only (Premium)
- **Usage**: `/world join [realm]`

**Arguments**:
- `realm` (Optional): The realm to join. Defaults to all.
