# `/realm unban`

Unbans a user from the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm unban <user> [realm] [reason] [attachment] [silent]`

**Arguments**:
- `user` (Required): The player to unban.
- `realm` (Optional): The realm to unban on. Defaults to all.
- `reason` (Optional): The reason for the unban.
- `attachment` (Optional): Proof for unban.
- `silent` (Optional): If True, the unban will not be logged.
