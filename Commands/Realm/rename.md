# `/realm rename`

Renames the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm rename <realm> <new_name>`

**Arguments**:
- `realm` (Required): The realm to rename.
- `new_name` (Required): The new name (max 32 chars).
