# `/realm slot`

Changes the active world slot of the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm slot <realm> <slot>`

**Arguments**:
- `realm` (Required): The realm to change.
- `slot` (Required): `1`, `2`, or `3`.
