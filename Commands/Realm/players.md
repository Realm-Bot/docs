# `/realm players`

View currently online players.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm players [realm]`

**Arguments**:
- `realm` (Optional): The realm to view. Defaults to all.
*Note: Display format (Compact vs Detailed) is configured in your server settings.*
