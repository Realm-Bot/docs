# `/realm invite`

Invites a user to the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm invite <user> [realm]`

**Arguments**:
- `user` (Required): The player to invite.
- `realm` (Optional): The realm to invite to. Defaults to all.
