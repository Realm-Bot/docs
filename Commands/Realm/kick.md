# `/realm kick`

Kicks a user from the Realm (removes them from the player list).

- **Permissions**: Authorized Users Only
- **Usage**: `/realm kick <user> [realm] [reason]`

**Arguments**:
- `user` (Required): The player to kick.
- `realm` (Optional): The realm to kick on. Defaults to all.
- `reason` (Optional): The reason for the kick.
