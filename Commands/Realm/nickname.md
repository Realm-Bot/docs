# `/realm nickname`

Changes the Realm's nickname within the bot (Discord command list).

- **Permissions**: Authorized Users Only
- **Usage**: `/realm nickname <realm> <nickname>`

**Arguments**:
- `realm` (Required): The realm to nickname.
- `nickname` (Required): The new nickname (max 32 chars).
