# `/realm backup-create`

Creates a new backup of the Realm.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm backup-create <realm> [name]`

**Arguments**:
- `realm` (Required): The realm to backup.
- `name` (Optional): A custom name for the backup.
