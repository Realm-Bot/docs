# `/realm lastseen`

Check when a specific player was last seen.

- **Permissions**: Authorized Users Only
- **Usage**: `/realm lastseen <user>`

**Arguments**:
- `user` (Required): The player to check.
*Note: Limited to the last 1000 members.*
