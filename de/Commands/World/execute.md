# `/world execute`

Führt einen Konsolenbefehl auf dem Realm aus.

- **Erlaubnis**: Nur autorisierte Benutzer (Premium).
- **Nutzung**: `/world execute <command> [realm]`

**Argumente**:
- `command` (Erforderlich): Der auszuführende Befehl (z.B. `/time set day`).
- `realm` (Optional): Der Realm, auf dem der Befehl ausgeführt werden soll. Standardmäßig alle.
