# `/world broadcast`

Sendet eine Nachricht in den In-Game-Chat.

- **Erlaubnis**: Nur autorisierte Benutzer (Premium).
- **Nutzung**: `/world broadcast <message> [realm]`

**Argumente**:
- `message` (Erforderlich): Die Nachricht, die an den Server gesendet werden soll.
- `realm` (Optional): Der Realm, an den gesendet werden soll. Standardmäßig alle.
