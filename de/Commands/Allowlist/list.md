# `/allowlist list`

Zeigt die gesamte Erlaubtliste an.

- **Erlaubnis**: Nur autorisierte Benutzer (Premium)
- **Nutzung**: `/allowlist list [from]`

**Argumente**:
- `from` (Optional): Paginierungsversatz (Start ab Index X).
