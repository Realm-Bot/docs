# `/realm recents`

Zeigt Spieler, die kürzlich online waren.

- **Erlaubnis**: Nur autorisierte Benutzer.
- **Nutzung**: `/realm recents <realm>`

**Argumente**:
- `realm` (Erforderlich): Der Realm zum Überprüfen.
