# `/realm close`

Schließt den Realm. Verhindert, dass Spieler beitreten können.

- **Erlaubnis**: Nur autorisierte Benutzer.
- **Nutzung**: `/realm close [realm]`

**Argumente**:
- `realm` (Optional): Der Realm, der geschlossen werden soll.
