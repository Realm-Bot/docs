# `/realm rename`

Benennt den Realm um.

- **Erlaubnis**: Nur autorisierte Benutzer.
- **Nutzung**: `/realm rename <realm> <new_name>`

**Argumente**:
- `realm` (Erforderlich): Der Realm, der umbenannt werden soll.
- `new_name` (Erforderlich): Der neue Name (max. 32 Zeichen).
