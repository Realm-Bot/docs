# `/rank`

Zeigt eine Rangkarte für einen Spieler an, die sein Level und die durch das Spielen auf dem Realm gesammelten Erfahrungspunkte anzeigt.

- **Erlaubnis**: Nur autorisierte Benutzer.
- **Nutzung**: `/rank <realm> [user]`

**Argumente**:
- `realm` (Erforderlich): Der Realm, in dem der Rang überprüft werden soll.
- `user` (Optional): Der Nutzer zur Überprüfung. Standardmäßig du selbst.
