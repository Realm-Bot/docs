# `/warn remove`

Entfernt eine Verwarnung von einem Spieler.

- **Erlaubnis**: Nur autorisierte Benutzer.
- **Nutzung**: `/warn remove <user> <reason> [realm]`

**Argumente**:
- `user` (Erforderlich): Der Spieler, dessen Verwarnung entfernt werden soll.
- `reason` (Erforderlich): Der ursprüngliche Verwarnungsgrund, der entfernt werden soll.
