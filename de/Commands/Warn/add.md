# `/warn add`

Erteilt einem Spieler eine Verwarnung. Wenn die Verwarnungspunkte den Schwellenwert überschreiten, kann der Spieler automatisch gebannt werden.

- **Erlaubnis**: Nur autorisierte Benutzer.
- **Nutzung**: `/warn add <user> <reason> [realm]`

**Argumente**:
- `user` (Erforderlich): Der Spieler, der verwarnt werden soll.
- `reason` (Erforderlich): Der Grund für die Verwarnung. Muss einem konfigurierten Grund entsprechen.
- `realm` (Optional): Der Realm, auf dem verwarnt werden soll. Standardmäßig alle.
