# Allowlist Commands

The Allowlist is a server-level Realm Bot exemption list. It is separate from Minecraft Realm membership and does not invite a player to a Realm.

All Allowlist commands require a connected server and Realm Bot Premium. Add, list, and remove also use their named Realm Bot command permissions; check is available without a custom command-role assignment.

Allowlisted players may be exempt from supported automated protections. Review [Bot Detection](<../../Realm Modules/bot-detection.md>), [Member Gate](<../../Realm Modules/member-gate.md>), and [Skin Filtering](<../../Realm Modules/skin-filtering.md>) before deciding who should be exempt.

## Commands

- [`/allowlist add`](add.md) - add a player.
- [`/allowlist check`](check.md) - check whether a player is allowlisted.
- [`/allowlist list`](list.md) - display the current list.
- [`/allowlist remove`](remove.md) - remove an exemption.

For shared failures, see [Command Troubleshooting](../troubleshooting.md).
