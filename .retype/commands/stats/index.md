# Stats Commands

Stats commands expose progression recorded by the [Leveling System](<../../Realm Modules/leveling-system.md>). They are separate from Realm activity history and the Scoreboard Leaderboards module.

Both commands require a connected server but do not use Realm Bot's custom command-role permission map and do not require Premium.

## Commands

- [`/rank`](rank.md) - generate a player's Leveling rank card.
- [`/leaderboard`](leaderboard.md) - open the server's public web leaderboard.

For recorded session history, use [`/realm playtime`](../Realm/playtime.md) or [`/realm sessions`](../Realm/sessions.md). For shared failures, see [Command Troubleshooting](../troubleshooting.md).
