# `/dashboard`

Provides buttons to the Realm Bot Dashboard home, account settings, and the current Discord server's settings when available.

## Syntax

`/dashboard`

No Realm Bot custom command permission, connected account, or Premium subscription is required. The command must still be used in a Discord server.
