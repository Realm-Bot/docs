# `/invite`

Provides buttons to invite Realm Bot to another Discord server and join the Realm Bot support server.

## Syntax

`/invite`

No Realm Bot custom command permission, connected account, or Premium subscription is required. The Discord member completing the bot invitation must have sufficient authority in the destination server.
