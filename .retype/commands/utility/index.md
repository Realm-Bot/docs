# Utility Commands

Utility commands cover server setup, service links, subscriptions, and operational information.

Public link commands do not require a connected server account or a Realm Bot command permission, although they still run in a Discord server. Connect, disconnect, and bot information have their own permission requirements.

## Setup

- [`/connect`](connect.md)
- [`/disconnect`](disconnect.md)

## Links and Support

- [`/dashboard`](dashboard.md)
- [`/help`](help.md)
- [`/invite`](invite.md)
- [`/premium`](premium.md)

## Diagnostics

- [`/botinfo`](botinfo.md)

Use `/disconnect` and account migration actions carefully. Record important configuration before changing the server association. For shared failures, see [Command Troubleshooting](../troubleshooting.md).
