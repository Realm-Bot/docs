# Frequently Asked Questions

Here you can find some of the most frequently asked questions about Realm Bot, taken from our support channels. If you have a question that isn't answered here, feel free to ask in our [Discord server](https://discord.gg/realmbot).

## General FAQ

### I'm new to Discord. How do I add a bot to my server?

Adding a bot to your server is a simple process. First, you need to have the "Manage Server" permission in the server you want to add the bot to. Then, visit the [Realm Bot website](https://www.realmbot.dev) and click the "Invite to Server" button. Follow the instructions to authorize the bot and select the server you want to add it to.

### Does Realm Bot support Minecraft Java Edition?

No, Realm Bot is designed specifically for Minecraft Bedrock Edition (MCBE) realms. It does not support Minecraft Java Edition servers.

### Is Realm Bot free to use?

Yes, Realm Bot is free to use with a wide range of utility features available at no cost. Some more advanced features are available to premium subscribers, but the core functionality of the bot is free for all users.

### How can i get Realm Bot premium and what are the benefits?

Realm Bot premium is available for a small monthly fee. You can purchase a premium subscription by visiting the [Realm Bot website](https://www.realmbot.dev/premium) and clicking the "Upgrade to Premium" button. Premium subscribers enjoy additional features such as advanced moderation tools, priority support, and more.

### Does the bot have to be ingame to manage my realm?

No, Realm Bot does not need to be in the game to manage your realm. You can control your realm directly from Discord, making it easy to manage your server even when you're away from the game. However, the bot is required to be in your Realm to relay chat messages between Discord and the game, as well as to perform certain actions like member gate, whitelist, bot detection, and more.

### What permissions does Realm Bot require to function?

Realm Bot requires a variety of permissions to function correctly. When adding the bot to your server, you will be prompted to grant the necessary permissions. Ensure that the bot has the following permissions:

- Mange Roles
- Mange Channels
- Create Invite
- Manage Nicknames
- View Channels
- Send Messages
- Embed Links
- Attach Files

### How do i allow other users to run commands?

By default, only users with the "Administrator" permission can run commands with Realm Bot. If you want to allow other users to run commands, you can create a role with the necessary permissions and assign it to those users. To do this, follow these steps:

1. Head to [Realm Bot's website](https://www.realmbot.dev) and log in with your Discord account, then select your server.
2. Navigate to the "Permissions" tab and create a select the role with the permissions you want to grant.
3. There, you can use the toggle to enable or disable the role's ability to run specific commands.

### When running /connect, I get an error message. What should I do?

If you encounter an error message when running the `/connect` command, there are a few things you can try to resolve the issue:

1. Ensure that you have connected the correct xbox account that is linked to your realm (MCBE realms only).
2. Make sure that you have the necessary permissions to run the command. If you are not the server owner or an administrator, you may not have the required permissions.
3. Check that the bot has the necessary permissions to function correctly. If the bot is missing any required permissions, it may not be able to complete the connection process.

### How do I report a bug or suggest a feature?

If you encounter a bug while using Realm Bot or have a feature suggestion, you can report it on our [Discord Server](https://discord.gg/realmbot) in the bug report channel. Our team will review your report and work to address the issue as quickly as possible. We appreciate your feedback and suggestions for improving Realm Bot!

### Is realm bot open source?

No, Realm Bot is not open source.
