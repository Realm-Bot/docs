# Moderation

## Overview

The moderation module in Realm Bot provides a range of tools and commands to help you manage your Realm via Discord. Allowing you to remove, block and unban members.

## How to setup moderation

By default, Realm Bot moderation commands are enabled for all users with the "Administrator" permission. If you want to allow other users to run moderation commands look at the [permissions](#permissions) section.

## Related Pages

Log channels are a great way to keep track of moderation actions taken by Realm Bot. You can set up a log channel to receive notifications when a user is warned, kicked, or banned from your server.

## Commands

| Command                                      | Description                   | Simple Usage        |
| -------------------------------------------- | ----------------------------- | ------------------- |
| [!badge /realm ban](/commands/realm-ban)     | Bans a user from your Realm   | /realm ban [user]   |
| [!badge /realm kick](/commands/realm-kick)   | Kicks a user from your Realm  | /realm kick [user]  |
| [!badge /realm unban](/commands/realm-unban) | Unbans a user from your Realm | /realm unban [user] |
