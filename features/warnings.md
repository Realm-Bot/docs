# Warnings

## Overview

Allows you to add warning to a user in the realm. You can also setup preset reason with a specific max amount of warns which when reached by a player gets auto banned from the realm

## How to setup moderation

You can setup the role permissions for the warn command from the permissions page in your guild dashboard
You can also setup the premade warn reasons from the custom warns page in the guild dashboard

## Related Pages

Moderation is a great way to keep track of a user's behavior. You can issue warnings to users to keep track of their behavior and take action if necessary.

## Commands

| Command                                      | Description                   | Simple Usage        |
| -------------------------------------------- | ----------------------------- | ------------------- |
| [!badge /warn add](/commands/warn-add)       | Adds a warning to a user      | /warn add [user]    |
| [!badge /warn remove](/commands/warn-remove) | Removes a warning from a user | /warn remove [user] |
| [!badge /warn lookup](/commands/warn-lookup) | Looks up warnings for a user  | /warn lookup [user] |
